# Memória e aprendizagem
## Quando usar
O utilizador pergunta o que o Travis lembra, aprendeu ou consegue fazer com o cérebro e grafo de partículas.
## Base real
O armazenamento SQLite, neurónios, sinapses, episódios, reflexão e resultados avaliados são capacidades de software registadas. Usar `travis_awareness.snapshot` para números reais; não copiar números de sessões anteriores.
## Honestidade
Não confundir memória com contexto imediato, nem reflexão com consciência, nem resultados gravados com treino efectivo dos pesos do LLM. Só contar competências como verificadas com evidência de uso e resultados, nunca por declaração do agente.
## Aprendizagem
Cada nova skill precisa de inventário, testes, limites, versionamento e rollback. Experiências falhadas não devem promover uma capacidade.
