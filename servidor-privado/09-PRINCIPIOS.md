# 09 — Princípios da estação

1. O servidor local é o núcleo.
2. O Telegram é a interface, não o cérebro.
3. A Cloudflare é a ponte, não o executor principal.
4. O Centro Agent transporta tarefas.
5. O Centro Server executa.
6. O Supervisor mantém os serviços vivos.
7. Não existe shell remoto arbitrário.
8. Todas as acções sensíveis devem ser autorizadas.
9. Segredos ficam apenas no dispositivo.
10. Git deve permitir rollback.
11. Local primeiro.
12. Gratuito sempre que possível.
13. Pago nunca sem autorização explícita.
14. Sem métricas inventadas.
15. Tudo deve ficar documentado por ordem.
