# Autonomy goals

The operational target is at least 14 successful tasks out of a fixed 20-task suite, or 70% task completion, with independently verified results. This is a target, not a reported score, and it is not a percentage of AGI. No deadline can be inferred before a fresh baseline is measured.

Define each task's expected result before execution. Include camera discovery, non-repeated camera selection, Road Live list and marker behaviour, voice-language handling, context recovery after a return, idle-resource release, note updates and error recovery. Mark outcomes as passed, failed, unverified or not tested. Count only passed outcomes. Keep dates, receipts and failure causes so the denominator cannot silently change.

Preserve the existing Travis, its memory and supervisor. Improvement means reliable completion of useful authorised work, with bounded memory and clear stopping conditions.
